# Workspace Rules & Directives

## Documentation Auto-Update Rule
- Whenever fulfilling a user prompt that alters code, adds features, changes configuration, or completes system checks, **always update `SYSTEM_DOCUMENTATION_AND_ROADMAP.md`** (located at the workspace root) with the latest changes, features, status logs, or roadmap updates before completing the response turn.
- Ensure `SYSTEM_DOCUMENTATION_AND_ROADMAP.md` remains the authoritative source of truth for all current system features, architecture, database schemas, test credentials, and future roadmap phases.
